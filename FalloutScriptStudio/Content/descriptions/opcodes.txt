// VANILLA PROCEDURE HANDLERS:

Handler description_p_proc | - Handler for the detailed description of an object. | By default, the description set in the object's prototype is displayed. || Note: The procedure must contain script_overrides to prevent the standard description function from being executed at the same time.
Handler look_at_p_proc | - Handler called when looking at an object. By default, the name from the object's prototype is displayed. || Note: The procedure must contain script_overrides to prevent the standard function from being executed at the same time.
Handler damage_p_proc | - Handler called when the object takes damage. | The amount of damage received is passed via the fixed_param parameter. || Warning! If the damage was fully absorbed by armor, this handler is not called!
Handler use_p_proc | - Handler called when this object is used. | To get the item that was used on the object, use the source_obj function. || Note: This handler is not called for some item types when working with the inventory!
Handler use_obj_on_p_proc |  - Handler called when another object is used on this object. | Via the obj_being_used_with parameter it receives a pointer to the object that was used.
Handler use_skill_on_p_proc | - Handler called when a skill is used on the object. | Via the action_being_used parameter it receives the number of the skill used on the object (see DEFINE.H, Skill Equates section).
Handler combat_p_proc | - Handler executed during combat. | The number of the specific event that caused the call is passed as the fixed_param parameter: |   COMBAT_SUBTYPE_WEAPON_USED (1) - On a miss, or if there was a hit but no damage was dealt (sFall: Ray patch only) |   COMBAT_SUBTYPE_HIT_SUCCEEDED (2) - successful hit |   COMBAT_SUBTYPE_SEQUENCING (3) - combat sequence is checked (not used) |   COMBAT_SUBTYPE_TURN (4) - start of turn |   COMBAT_SUBTYPE_NONCOM_TURN (5) - the player enters combat mode (used for Melchior's pets)
Handler combat_is_starting_p_proc | - Handler executed each time before combat starts.
Handler combat_is_over_p_proc | - Handler executed each time before combat ends.
Handler critter_p_proc | - Handler responsible for the object's behavior, executed continuously several times per second. || Note: If this procedure is missing in a critter's script, errors may occur, and the first procedure found may be taken as this handler and be executed constantly.
Handler push_p_proc | - Handler called when an attempt is made to push the object.
Handler talk_p_proc | - Dialogue handler, called when an attempt is made to talk to the object.
Handler pickup_p_proc | - This handler has different meanings in item scripts and critter scripts. | In item scripts it is called when a critter tries to pick up this item, | for container objects - when a critter tries to open them or steal something. | In critter scripts it is called when an attempt is made to steal from those critters.
Handler drop_p_proc | - Handler called in the object's script when the self object is dropped on the ground.
Handler is_dropping_p_proc | - Handler called in a critter's script when it tries to drop an item.
Handler map_enter_p_proc | - Handler called when the player enters the map. | The value of the map flag "NON-VIRGIN MAP" is passed to the function via the fixed_param parameter.
Handler map_exit_p_proc | - Handler called when the player leaves the map.
Handler map_update_p_proc | - Handler called when the map is updated. | The update occurs every 250 game ticks, one second equals 10 ticks.
Handler destroy_p_proc | - Handler called when the object that the script belongs to is destroyed.
Handler spatial_p_proc | - Handler called in the script of an object when another object passes over it.
Handler timed_event_p_proc | - Timed event handler. | Called when a previously set timer fires. | Via the fixed_param parameter the function receives the value of the fired timer set in add_timer_event.
Handler start | - Handler called when the script starts, i.e. each time the player enters the map.
